An entry for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on [make.fun](https://make.fun).

One original haiku about debugging, in the 5-7-5 syllable shape:

> I delete the line
> the whole app wakes up again
> it was never used

`main.py` writes exactly that text to `/output/entry.txt`.
